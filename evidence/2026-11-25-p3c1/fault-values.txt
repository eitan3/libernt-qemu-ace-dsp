## On the command line: -device intel-hda-ace,bus=pcie.0,addr=1b.0,fault=<value>

A bad value is refused when the device is realised (QEMU exits with the line below); a good one starts QEMU
(stopped here one second later).

```
fault=never-reply=99 -> fault=never-reply=99: intel-hda-ace: fault 'never-reply': '99' is not a message type (0 to 31) 
fault=never-reply= -> fault=never-reply=: intel-hda-ace: fault 'never-reply': '' is not a message type (0 to 31) 
fault=never-reply=abc -> fault=never-reply=abc: intel-hda-ace: fault 'never-reply': 'abc' is not a message type (0 to 31) 
fault=ipc-status=5:32 -> fault=ipc-status=5:32: intel-hda-ace: fault 'ipc-status': '32' is not a message type (0 to 31) 
fault=ipc-status=5:19:1 -> fault=ipc-status=5:19:1: intel-hda-ace: fault 'ipc-status': '19:1' is not a message type (0 to 31) 
fault=ipc-status -> fault=ipc-status: intel-hda-ace: fault 'ipc-status' needs a value (=<status>, or =<status>:<type> for one message type) 
fault=never-power=1 -> fault=never-power=1: intel-hda-ace: fault 'never-power' takes no value 
fault=ipc-status=5:19 -> started (accepted)
fault=never-reply=19 -> started (accepted)
fault=ipc-status=5 -> started (accepted)
fault=never-reply -> started (accepted)

```
